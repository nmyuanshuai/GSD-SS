# GSD-SS
Grassland Survey Data Standardization System

## Files

- `Core Processing Layer Code.py` — main script
- `Standardized Output Table.xlsx` — output template with column headers
- `Test Folder.rar` — sample data

## Usage

1. Install dependencies: `pip install pandas openpyxl`
2. Update input/output paths in the main script
3. Run: `python "Core Processing Layer Code.py"`

**Note:** The full GUI application is not included here due to file size limits. This repository contains the core processing code only.
